# Changelogs

Drop a Markdown file named after the version you're releasing, e.g.
`0.10.99.md`. The release manager reads this file and embeds it in the
manifest's `changelog` field for the corresponding release.

Conventions:

- One file per release.
- Markdown body — bullet list is the typical format.
- The file is required: the release manager aborts if it can't find one.
